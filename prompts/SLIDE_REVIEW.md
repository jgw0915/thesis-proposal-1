# Reusable slide-review prompt

Inspect the current exported PPTX/PDF and (if available) the reference senior deck side by side. Score each slide for (1) factual fidelity to the thesis, (2) visual consistency with the documented senior style, (3) readability/projector legibility, (4) story flow, (5) diagram/editability and (6) scientific citations. Report actionable slide-numbered changes and distinguish blockers from optional polish. Do not report that unseen slides are verified. Fix issues when editable source is available; rerender after fixes and update `docs/WORK_STATUS.md`.
