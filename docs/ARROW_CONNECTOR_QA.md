# 箭頭、連接線與資料流方向 QA（必遵守）

**2026-11-16 起生效。** 適用於既有投影片的修訂，以及所有新批次。優先於以手動分離細線與三角形／chevron 製作箭頭的舊作法。

## 必要設計規範
1. **先定義語意，再畫箭頭。** 每條箭頭需有明確的來源物件（source）與目的物件（target），文字與箭頭方向應符合論文中的資料流、控制流程或依賴關係。不能只為了裝飾而加箭頭。
2. **端點中心對齊。** 水平箭頭應由來源盒右側中點出發，指向目的盒左側中點；垂直箭頭由來源盒下側中點出發，指向目的盒上側中點。允許為避免擁擠而使用明確的接入點，但必須保持視覺一致。
3. **整條箭頭採同一個 connector/arrow 物件**，優先用原生 PowerPoint 線型/直角 connector 及 end-arrowhead，不要以一段線加上獨立 chevron、三角形或文字符號假裝箭頭頭部，以避免 Canva 匯入／PPTX 匯出時產生位移。
4. **方向不得錯。** 箭頭尖端朝向目的物件，線不穿過節點或重要文字；不得有無端點、回頭指向自身、未解釋的交叉、懸空箭頭。分支方向與結果「是／否」、資料集 `fit/search/test` 等必須與最新版第三章一致。
5. **直角走線優先。** 多條來源匯流時用整齊的平行、直角線段、明確分支點或收斂節點；將箭頭尖端放在真正的目的節點邊界，避免箭頭指向空白。
6. **安全間距。** 箭頭線與卡片外緣保有合適間隙，箭頭頭部不被卡片覆蓋；線與標籤不重疊。相鄰箭頭保持一致粗細、顏色、箭頭尺寸和走線節奏。
7. **回饋迴圈須明確標注。** 「未收斂 → 更新權重 → 下一輪抽樣」要畫成具方向的回饋；「收斂／達上限 → 最後一輪集成 → 測試」不得畫成測試資料回流訓練。
8. **匯入後再檢查。** 不能只驗證本地 PPTX；需逐頁核對 Canva 實際渲染。匯入時若連接線分離或方向改變，該頁仍屬 QA 未通過。
9. **保留使用者修改。** 修訂既有 Canva 頁面前記錄原始頁碼、取得視覺檢查結果，優先只更動有問題的箭頭。若 Canva MCP 無法直接編輯 connector，先提供修訂版預覽／可編輯替換頁，不可不經確認就刪除既有頁。
10. **驗證時不只數形狀。** 應逐一列出箭頭的 source／target、端點、朝向、是否落在邊界或是否有交叉；必要時輸出 arrow audit 表、接續修正的 before/after PNG。

## 每批檢查清單
- [ ] 頁中所有有方向性的線與箭頭已盤點
- [ ] 每條箭頭的來源與終點正確，箭頭尖端朝向終點
- [ ] 水平／垂直中心對齊，沒有懸空或穿越主要內容
- [ ] 直角分支／匯流／回饋的方向與文字一致
- [ ] 箭頭為原生 connector 並設定 end-arrowhead（不使用獨立 chevron 模擬）
- [ ] 本地 PDF/PNG 與匯入 Canva 後的渲染均檢查
- [ ] 未更動不相關的使用者手動排版
- [ ] 問題頁碼、修正方式、是否已上線至主專案明確記錄

## 既有簡報稽核（第一次盤點）
已依目前可檢查的第一至三批可編輯 PPTX，找出具有 arrow/connector 的頁面：**6、7、8、11、12、14、15**。其餘頁面無明確箭頭圖形（分隔線不算）。上述舊版使用了拆開的線與 chevron，存在匯入後對位及方向風險。重新設計時應用一條真正的 connector 對應一個 flow edge。

現有 Canva 工具無直接修改線型 connector 幾何/箭頭端點的功能；替換已手動編修的頁面需要額外保護原稿並確認替換範圍，不應宣稱已透過 Canva 直接重畫原頁。
