# 投影片語言與來源標示規則（必遵守）
**採用日期：2026-11-16。** 本文件優先於先前所有「使用英文簡報」的規劃。

## 1. 語言
- 所有正式投影片的封面、標題、章節目錄、內文、圖示標籤、導覽列及結尾頁，**一律使用繁體中文（zh-TW）**。
- 技術名稱、公式、標準縮寫可以保留原文，例如 MNB、PSO、DNA、8-mer、KL、JMH，必要時首度出現附中文名稱。
- 不以原始學姊簡報的英文文字作為語言標準；僅參考其視覺風格。
- 講稿、備註及 QA 報告以繁體中文為預設；除非使用者另行指示。
- 圖中保留英文語料的情況須有明確教學目的，原則上改用繁體中文範例。

## 2. 來源與頁面底部
- **不得**在每頁底部另外放置縮小字級的「Sources / Source / Resource / 來源」字串、檔名、章節路徑、開發備註或與主要論述無關的引用列。
- 底部保留既定的章節導覽與頁碼即可；內容區可保留具有實質訊息且字體清楚的研究提醒。
- 需要學術歸屬時：在相應圖表、論述旁以可讀字級標出 `作者（年份）`；細節與完整書目放在講者備註、文獻總覽頁或參考文獻頁。
- 不可因為清除頁底小字而移除必要的學術歸屬，亦不得使外部研究概念冒充為本研究的原創貢獻。
- 每批完成後檢查：所有觀眾可見自然語言為繁體中文、沒有頁底細小來源列、不佔用導覽安全區、引用可追溯。

## 3. 保留使用者調整
- 編輯前讀取既有 Canva 最新版本，保存使用者手動修改的版面決策。
- 重製時建立新版本或備份；不得靜默覆蓋原作品。
- 應驗證匯入 Canva 後的文字可編輯，並以渲染檢查溢出、裁切與可讀性。

## 4. 數學公式與 Canva 主簡報（2026-11-16 新增）
- **最終使用者會以 PowerPoint 發表。** 公式在 Canva 階段以清晰可讀的佔位符或可選的 LaTeX Math 外掛預覽，原始 LaTeX 必須記錄於私有 manifest，待使用者匯出並上傳 PPTX 後，再轉換成 PowerPoint 原生可編輯的 Office Math。
- 不可將 Unicode 字元拼接、一般文字或 Canva 匯出圖片稱為「原生可編輯 PowerPoint 公式」。完成轉換後須檢查 OMML 和 PowerPoint 實際顯示。詳見 `docs/FINAL_POWERPOINT_EQUATIONS.md`。
- 後續製作須持續加入同一份 Canva 主簡報，**不得每批新建獨立正式簡報**；為技術性匯入而建立的中介設計不視為正式主專案。
- 合併完成須確認頁數、順序與使用者手動調整皆被保留。詳見 `docs/CANVA_MATH_AND_MASTER_WORKFLOW.md`。
