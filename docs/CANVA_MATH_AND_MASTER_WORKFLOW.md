# Canva 數學公式製作與單一主簡報作業規範

**2026-11-16 起生效。公式的最終輸出程序已由 `docs/FINAL_POWERPOINT_EQUATIONS.md` 更新（其優先度高於本檔較舊的 Canva LaTeX Math 強制要求）。** 此規範與 `AGENTS.md` 及 `docs/SLIDE_WRITING_RULES.md` 同時適用。

## 1. 公式與記號（必遵守）
- **更新決策：最終公式以 PowerPoint 原生可編輯的 Office Math 為準。** Canva 階段可使用易讀的數學佔位文字或選擇性以 Canva LaTeX Math 外掛預覽；不再強制在 Canva 先插入外掛。記錄每頁 LaTeX 來源，待 Canva 完成後由使用者匯出並上傳 PPTX，再轉換成 OMML。
- 原始 LaTeX 程式碼須與頁碼、對應論文章節及符號定義一起保存在私有的公式清單（manifest），方便未來重新生成；公開倉庫只保存作業程序，不得公開私有論文細節。
- 類別先驗、條件機率、求和索引、最佳化運算子、向量等應使用一致的排版，並與最新版 `Master-Thesis` 的公式與定義逐一核對，不能憑記憶改動。
- 正式公式建議採用深色 `#171717`、夠大的字級及適當留白，不可與頁碼、章節導覽或相鄰圖表碰撞。將外掛生成的公式視作單一設計元素，保留可重複使用的 LaTeX 原始碼。
- 不需把所有簡單數字和標籤都改成外掛：如「10 個類別」、「PSO」、「8-mer」可維持一般 Canva 文字；正式方程式和包含上下標的數學記號才使用 LaTeX。
- **目前 Canva API 不支援在此會話中直接操作 LaTeX Math 外掛。** 不需因此中斷簡報製作；請建立準確的 TeX manifest 並標記為「待最終 PPTX 原生公式後製」。若使用者自願使用 Canva 外掛，其公式可能作為圖片匯出，須於最終 PPTX 階段再替換；不得宣稱外掛公式已自動變為原生 PowerPoint 方程式。
- Canva LaTeX Math 外掛本身會將 LaTeX 排版為圖片物件；**後續修改仍可能需以保留的 LaTeX 原始碼重新生成**，不能假設圖片包含可編輯的公式來源。

## 2. 單一 Canva 主專案（必遵守）
- 只維護**一份持續延伸的 Canva 主簡報**，內含所有已完成且正確排序的投影片。工作主專案是使用者原本第 1–5 頁的專案，已合併第二批後共有 10 頁。
- 往後每批在本地生成、排版、QA 後，應以 **Canva `merge_designs` 的 `modify_existing_design`** 將新頁面附加至既有主專案；**不得每批另外開一份 Canva 專案當成正式交付品**。
- 如果編輯工具無法直接在主專案建立頁面，得將中介檔匯入暫時 Canva 設計以供合併；合併並驗證後，仍以主專案為唯一正式編輯位置，明確註記中介設計不是主專案。
- 每次合併都要逐頁檢查**頁面實際順序**及視覺頁碼。注意部分合併操作可能出現逆序，因此不可只憑總頁數判定成功。
- 保留使用者在既有主簡報的所有手動修改；絕不以重新匯入批次替換既有頁面或重置手動排版。
- 若涉及刪除、取代或重大改動已完成內容，先提出差異與預覽並取得使用者同意；Canva 編輯交易變更在正式保存前須先提供預覽與確認。
- 私有 Canva 編輯連結與論文內容**不得寫入目前公開的 GitHub repository**。私有 manifest 可在會話工作區或個人安全儲存區留存。
