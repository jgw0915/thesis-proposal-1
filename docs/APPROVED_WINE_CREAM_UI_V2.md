# 選定之酒紅／米白學術資訊圖表版型

**採用日期：2026-11-16。** 使用者明確選定目前圖片式樣作為論文 Proposal 之後各頁的 UI/UX 方向。本檔為公開安全的設計規範，不包含使用者圖片、學姊原稿或私人簡報內容。

## 視覺結構
- 畫布 16:9，使用 20 × 11.25 in 版面；暖米白 `#FCFAF7`、酒紅 `#8F1931`（深酒紅 `#731427`）、棕金 `#9C794C`、深灰 `#292527`、奶茶色卡片 `#F6F0E7`。
- 巨大的繁體中文 Serif 標題、簡明 Sans 正文，優先使用 Noto Serif CJK TC 與 Noto Sans CJK TC。副標題與圖說不得過小。
- 上方小型「投影片 N」斜切標籤（酒紅＋棕金）及 1.1／1.2／1.3 章節分頁，固定的位置、尺寸、間距。
- 圖解：圓角白卡、淺米色資訊帶、細邊框、淡陰影、1–2 個主色階。並排卡片使用相同外框、對齊標題與數據。
- 封面可用**獨立裝飾性**淡化校園建築圖片；全部正式文字／卡片／表格／箭頭應保持原生可編輯物件。禁止整頁使用單張扁平截圖取代。
- 圖中箭頭必須使用真正 connector、端點中心對齊、符合正確資料流方向（見 `docs/ARROW_CONNECTOR_QA.md`）。
- 講者看到的每頁只有一個主訊息，不做無意義裝飾或細小來源註記。

## 頁面骨架
1. 封面：學校與系所、論文完整題目、研究生／指導教授、審查委員、日期、時間及地點；封面不需要章節頁底列。
2. 簡報大綱：**確定為第 2 頁**，完整五個章節；不替換成研究缺口。
3. 緒論 1.1：**研究背景**，文件與 DNA 重疊 8-mer 的計數特徵對比圖。
4. 緒論 1.2：MNB 的機率參數**座標**數負擔對比（不得引用圖片生成錯誤的 `|Θ| = (M−1) × 2^p` 或錯用 `p=13/10`）。
5. 緒論 1.3：三項研究目標與核心問題。

## 頁底章節列（2026-11-16 新規則）
- 第 3 頁以後的頁底，只顯示 **`緒論｜文獻探討｜研究方法｜實驗規劃｜附錄`**（當前章節高亮）與頁碼。
- **不再包含 `目錄`。** 目錄本身是第 2 頁，另有獨立排版，不需重複進入章節導覽。
- 舊版頁面有 `參考文獻` 字樣也應在未來批次逐頁改成 `附錄`；不得因為一批改完就宣稱全份已修訂。
- 保留使用者手動調整並先備份再替換。每批仍在同一份既有 Canva 主簡報繼續修改。

## 嚴謹性與後製
- 細節來自權威論文而不是生成圖片。展示資料／公式不可被視覺範例的錯字或錯式覆蓋。
- 第 3、4 頁數學式的 LaTeX 原始碼在私人交付物保留；最終 Canva→PowerPoint 匯出後轉為原生 Office Math（OMML）。
- 每批 PDF/PNG 渲染後進行內容、箭頭、可編輯性、字級、裁切 QA，才可替換 Canva。
