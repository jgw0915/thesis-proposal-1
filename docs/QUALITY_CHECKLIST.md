# Slide-quality acceptance checklist

## Scientific integrity
- [ ] Every algorithm step matches current thesis Chapter 3.
- [ ] No training/search/test information leakage in graphics or speech.
- [ ] MNB probabilities satisfy appropriate nonnegative, normalized constraints.
- [ ] Symbol definitions do not conflate Chapter 2's and Chapter 3's K/M.
- [ ] Correctly distinguish document term counts from DNA 8-mer counts.
- [ ] References on slides correspond to actual cited work.
- [ ] Hypotheses and plans are not represented as experimental results.

## Visual quality
- [ ] 16:9 canvas and consistent #F8F8F8 / #A31F34 / #8C6E4A grammar.
- [ ] Large serif italic section titles, clean content font and repeating footer.
- [ ] Active nav tab and slide counter are consistently positioned.
- [ ] Figures are editable / diagrams have source files.
- [ ] Equations are readable in full-screen projection.
- [ ] No overflowing text boxes, cropped diagrams, missing fonts, broken symbols.
- [ ] Not more than one dominant idea per slide.
- [ ] Senior style recognizable without copying unrelated experiment content.

## Review / delivery
- [ ] Compare slide PNG montage against source reference style.
- [ ] Render final PPTX to PDF for visual inspection.
- [ ] Proofread English spelling, units and axis labels.
- [ ] Export revised PPTX and PDF to proper directories.
- [ ] Update `docs/WORK_STATUS.md` and `docs/DECISION_LOG.md`.
- [ ] Verify links and source commit are recorded before defense.
